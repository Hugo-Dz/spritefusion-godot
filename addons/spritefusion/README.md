# Sprite Fusion

Generate pixel-art sprites and animations from the Godot editor.

## Connect

Open the Sprite Fusion dock, click `Connect`, and approve the device code in your browser.

## Generate

Enter a prompt and click `Generate`. Generated images are saved under `res://spritefusion/generated`.

## Animate

After generating an image, select it as the source image, enter an animation prompt, and click `Animate`.
